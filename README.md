## About This Project

Hello, I'm Sarvesh Soumil, and I'd like to welcome you to **QuantumCalc: The Terminal's Logic Engine**. I designed this project to be the ultimate all-in-one tool for both complex scientific calculations and everyday unit conversions, all accessible from the command line. I built this application entirely in **Java**, focusing on creating a utility that is not only powerful and efficient but also showcases my approach to clean and user-centric software development.

My goal was to create a single, comprehensive tool that could replace the need for multiple separate applications. To achieve this, I architected the program into two core modules: a **Scientific Calculator** and a **Unit Converter**.

### **The Scientific Calculator** 🧮

I wanted to build more than just a basic four-function calculator. My scientific module is engineered to handle a wide array of mathematical tasks with precision. The capabilities I included are:
* **Basic Arithmetic:** I implemented the standard addition, subtraction, multiplication, and division, ensuring I included robust error handling for edge cases like division-by-zero.
* **Advanced Functions:** I added features to effortlessly compute powers (`pow`), square roots (`sqrt`), natural logarithms (`log`), and base-10 logarithms (`log10`).
* **Trigonometry:** To make it truly useful for students and professionals, I included `sin`, `cos`, and `tan` functions. I designed it to intelligently accept inputs in degrees and handle the conversion to radians internally, which I felt would create a much smoother user experience.

### **The Unit Converter** ⚖️

I designed the unit converter module with practicality in mind, providing quick and accurate conversions that are useful in a variety of real-world scenarios:
* **Temperature:** I included seamless conversions between Celsius, Fahrenheit, and Kelvin.
* **Currency:** For a quick reference, I added currency conversions between major pairs like USD, EUR, and INR using fixed, demonstrative rates.
* **Weight:** I made sure to support both metric and imperial units, allowing for easy switching between kilograms, grams, pounds, and ounces.

### **My Technical Approach** ✨

Beyond the features, I am particularly proud of the technical implementation. I wrote the code to be highly **modular**, separating logic into distinct methods. This approach not only makes the code more organized and readable but also ensures it's easy for me or others to extend in the future.

Even though it’s a console application, I wanted to create a more engaging user interface. I used **ANSI color codes** to build a dynamic, intuitive, and visually organized experience. Finally, a key focus for me was robust **error handling**. I implemented checks throughout the application to gracefully manage invalid user inputs, ensuring a smooth and crash-free operation.

Thank you for checking out my project. I hope you find it to be a powerful, lightweight calculation utility and a clear showcase of my passion for building clean, efficient, and user-focused software in Java.
